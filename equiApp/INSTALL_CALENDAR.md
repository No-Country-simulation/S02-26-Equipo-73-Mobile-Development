# Instalación de react-native-calendars

## 1. Instalar la librería

```bash
npm install react-native-calendars
```

## 2. Para Expo (prebuild)

Si usas Expo con custom dev client:

```bash
npx expo prebuild --clean
npx expo run:android
# o
npx expo run:ios
```

## 3. Verificar instalación

La librería debería aparecer en package.json:

```json
{
  "dependencies": {
    "react-native-calendars": "^1.1306.0"
  }
}
```
