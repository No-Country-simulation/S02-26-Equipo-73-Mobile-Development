# Fuentes de la aplicación

## Tipografía: Syne

Descarga la fuente Syne desde Google Fonts:
https://fonts.google.com/specimen/Syne

### Archivos necesarios:

Descarga los siguientes archivos TTF y colócalos en esta carpeta:

- `Syne-Regular.ttf` (Weight: 400)
- `Syne-Medium.ttf` (Weight: 500)
- `Syne-SemiBold.ttf` (Weight: 600)
- `Syne-Bold.ttf` (Weight: 700)
- `Syne-ExtraBold.ttf` (Weight: 800)

### Pasos para instalar:

1. Ve a https://fonts.google.com/specimen/Syne
2. Haz clic en "Download family"
3. Extrae el archivo ZIP
4. Copia los archivos `.ttf` que necesites a esta carpeta
5. Después de agregar las fuentes, ejecuta `npm run prebuild` para regenerar los archivos nativos
